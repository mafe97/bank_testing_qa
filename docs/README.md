# Documentación del laboratorio

Este folder contiene la documentación del taller de pruebas unitarias e integración del proyecto de préstamos del Banco Pascual Bravo.

## Archivos

- `Laboratorio_pruebas_unitarias_integracion.md`: resumen del enunciado, objetivos, criterios y evidencia del trabajo realizado.
- `Evidencias_pruebas.md`: detalle de pruebas ejecutadas, resultados y cobertura.
- `SonarQube_y_calidad.md`: resumen del análisis estático con SonarQube y SonarLint.
